# Signal Lab | Threads 流量實驗室

繁體中文、深色、行動版優先的 Threads 私人實驗工作區。

## 使用

- 總覽：查看各篇貼文最新快照的觀看、觸及、檔案瀏覽與追蹤。
- 貼文紀錄：新增、編輯與搜尋，補充多次快照及原始圖片。
- 經營策略與實驗：保存目標、原則、討論來源、具體行動、成功指標、比較窗口與復盤結果；可關聯貼文、更新狀態及篩選進度。
- 資料與備份：匯出貼文、圖片與策略；新版可完整還原策略，舊版備份保留既有策略。
- 所有觀測時間以台灣時間記錄。不同觀測窗口分開比較，觀看與觸及分開呈現。

公開原始碼不包含使用者的貼文數據、原始截圖、策略內容或存取憑證。

## 開發與驗證

使用 Node 22.13+，依專案鎖定檔安裝相依套件。

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node tests/integration.mjs
node tests/strategy-view.mjs
```
